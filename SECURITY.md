# Sicurezza e dati

Non allegare a issue pubbliche manoscritti, immagini private, token, secret OAuth, archivi o file di configurazione reali. Descrivere il problema con una fixture sintetica e dati rimossi.

La release parte senza progetti e senza account. La configurazione Google appartiene solo all’utente e viene importata esplicitamente. I file esterni registrati nel dossier non sono incorporati nel backup o nello scambio. Proteggere l’account Windows e conservare backup indipendenti.

Beta sperimentale, installer senza firma digitale. SHA-256 della release disponibile nei checksum. I controlli automatici sono parziali e non costituiscono certificazione di sicurezza o stampa. Le verifiche di conflitto/rete sono in parte simulate: non equipararle a garanzie su tutti i dispositivi.
